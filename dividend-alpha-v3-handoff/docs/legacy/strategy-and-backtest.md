## 1. 策略总结构：Core-Satellite（核心-卫星）

```
                    总资产 100%
                         │
        ┌────────────────┴────────────────┐
        │                                 │
   核心仓 CORE 70%                  机动仓 TACTICAL 30%
   （盾 · 锁仓吃息）                （矛 · 做T/波段）
        │                                 │
  15-25 只高股息                    同一批标的的额外仓位
  跨行业分散（单行业≤25%）          + 现金缓冲
  季度/半年再平衡                    T+1 约束下正T/倒T
  永不动用于做T                      信号驱动，1月内了结
        │                                 │
   收益：股息 4-6% + 估值修复        收益：目标 5-8%（需验证）
```

**为什么必须物理隔离**：
- 如果做T动的是核心仓，一次卖飞就会永久损失一只高股息标的的持仓——这是最贵的错误
- 隔离后可以在归因时**干净地拆出增强层收益**
- 隔离后可以单独关掉增强层做 A/B 对照（B2 vs S0）

### 2.4 再平衡规则

| 触发条件 | 动作 |
|---|---|
| 季度末（3/6/9/12 月最后交易日） | 常规再平衡，仅当权重偏离 > 3pct 才调整 |
| 单票权重 > 10%（涨出来的） | 减回 8%，减仓部分进现金或补入低配标的 |
| 标的触发卖出硬规则 | 立即换仓（不等季末） |
| 行业权重 > 28% | 强制再平衡 |

**卖出硬规则**（避免沉没成本）：
- 连续分红中断（当年不分红）
- 股息率跌破 2.5%（股价涨太多）
- 分红率 > 100%（吃老本）
- 扣非净利连续 2 年下滑 > 20%
- 出现重大违规/退市风险

## 3. 增强层：A股 T+1 下的做T设计

### 3.1 必须先接受的现实

| 现实 | 后果 |
|---|---|
| **T+1**：当日买入不可当日卖出 | 做T**必须依托已有底仓**，不能空手做T |
| 印花税卖出 0.05% + 佣金双边约 0.05% + 过户费约 0.002% | **个股单次往返 ≈ 0.10%**（费）+ **0.1-0.2%（滑点）** ≈ **0.2-0.3%** |
| ETF 免印花税 | **ETF 往返 ≈ 0.15%**，成本优势巨大 |
| 红利税：持股 ≤1月 20%，1月-1年 10%，>1年 0% | 频繁交易会**额外损失红利税**，这是隐性成本 |
| 高股息股波动率低（年化 15-20%） | 日内/3日空间小，做T单次目标只能是 **1.5%-3%** |

> 💡 **结论**：做T单次目标 1.5-3%，成本 0.2-0.3%，**成本占目标收益的 10-20%**。因此：
> - 胜率必须 > 55% 才有正期望
> - 只在**强信号**出手，绝不为做T而做T
> - 优先考虑用 **红利ETF（如 510880/515180）做T**，成本减半且天然分散

### 3.2 T+1 仓位账户模型（★ 回测正确性的关键）

```python
@dataclass
class T1Position:
    shares_total: int      # 总持仓
    shares_locked: int     # 当日买入锁定，次日释放
    lots: list[TradeLot]   # FIFO 批次

    @property
    def available(self) -> int:
        return self.shares_total - self.shares_locked   # ★ 可卖数量

    def on_buy(self, n, price, date):
        self.shares_total += n
        self.shares_locked += n          # 当日锁定
        self.lots.append(TradeLot(date, price, n))

    def on_new_day(self):
        self.shares_locked = 0           # ★ 过夜释放

    def on_sell(self, n, price, date):
        if n > self.available: raise T1Violation()
        self.shares_total -= n
        # FIFO 出库计算成本与红利税
        ...
```

**回测 Broker 必须实现**：任何 `sell` 都要先校验 `n <= available`，否则该笔交易非法。
这是绝大多数"做T回测很赚钱"的结论失真的**第一原因**。

### 3.3 两种做T模式

| 模式 | A股俗称 | 操作 | 前提 | 适用 |
|---|---|---|---|---|
| **正T** | 先买后卖 | 早盘低开/急跌时买入 N 股 → 当日反弹后卖出**昨日已有的** N 股 | 有底仓 + 有现金 | 低开、急跌日 |
| **倒T** | 先卖后买 | 高开冲高时卖出底仓 N 股 → 当日回落买回 N 股 | 有底仓（可卖） | 高开、冲高日 |

两种都合法，系统都支持，由信号决定用哪种。核心不变的是：**收盘时持仓数量不变**（仓位守恒），赚的是日内价差。

> 注意：正T 中"当日买入的 N 股"收盘仍在账户里，而被卖掉的是"昨日的 N 股"——净数量不变，但**成本价改变**，且 FIFO 上卖掉的是最早的批次（通常已满 1 年，红利税为 0）。

### 3.4 做T信号族（3-7日）

| 信号 | 逻辑 | 触发条件（示例） | 反向平仓 |
|---|---|---|---|
| **均值回归** | 价格偏离 MA20 过大回归 | `|close - MA20| / MA20 > 2× ATR20/MA20` 且 RSI6 > 75 或 < 25 | 回归至 MA20 ± 0.5 ATR |
| **布林极端** | 触及布林上/下轨 | `close >= BB_up(20,2)` 且成交量放大 1.3× | 回中轨 |
| **量价背离** | 价升量缩 / 价跌量增 | 5日量价背离 + 处于震荡区间 | 3-7 日时间止损 |
| **支撑压力** | 前高/前低/整数关口 | 距支撑位 < 0.8% 且未破位 | 破位止损 |
| **超跌反弹** | 连跌 + 偏离 MA60 | 5日跌幅 > 5% 且 `close < MA60 × 0.95` | 反弹至 MA20 |

**做T通用过滤（必须全部满足）**：
```
✓ 标的处于震荡状态（ADX(14) < 25）—— 趋势中做T是找死
✓ ATR20 / close ≥ 0.8%          —— 波动太小，空间不够覆盖成本
✓ 预期净收益 ≥ 0.8%（且 ≥ 3× 往返成本）
✓ 赔率 ≥ 1.5 : 1
✓ 距财报披露日 > 3 个交易日      —— 避开业绩雷
✓ 非涨跌停、非停牌
✓ 机动仓可用仓位/现金充足
```

### 3.5 波段信号族（1月以内）

| 信号 | 逻辑 |
|---|---|
| 中期动量 | 20日涨幅排名 + MA60 上方 + 成交量确认 |
| MACD 金叉 | 日线 MACD 金叉且柱状体连续 3 日放大 |
| 估值分位回归 | PB 分位从 <20% 回升，突破 20 日均线 |
| 行业轮动 | 申万一级行业 20 日动量排名前 3 且本组合该行业低配 |
| 资金面 | 主力净流入连续 3 日为正 / 北向持股比例上升 |

波段仓位独立于做T仓位，建议机动仓内部再切：`做T 15% / 波段 10% / 现金 5%`。

## 5. 成本模型（★ 决定成败）

### 5.1 单笔往返成本

```
股票往返成本 = 买入佣金 + 卖出佣金 + 卖出印花税 + 双边过户费 + 双边滑点
            ≈ 0.025% + 0.025% + 0.05% + 0.002% + 0.2%
            ≈ 0.30%

ETF 往返成本 ≈ 0.025%×2 + 0（免印花税）+ 0.1%（滑点更低） ≈ 0.15%
```

### 5.2 年度成本侵蚀测算（★ 震撼数字）

| 年做T次数 | 单次成本 | 年换手率 | **年成本侵蚀** |
|---|---|---|---|
| 30 次 | 0.30% | ~1.0 | **-3.0%** |
| 60 次 | 0.30% | ~2.0 | **-6.0%** |
| 120 次 | 0.30% | ~4.0 | **-12.0%** |

> 这意味着：**如果你的做T策略一年做 60 次，它必须先赚够 6% 才能打平**。
> 这也是为什么 `min_expected_net_pct` 与 `max_signals_per_day` 是硬约束。

### 5.3 红利税（隐性成本，最易被忽略）

卖出时按 **FIFO** 匹配买入批次，按持股天数计税：

```python
def dividend_tax(lot, sell_date, cash_per_share, shares):
    days = (sell_date - lot.buy_date).days
    rate = 0.20 if days <= 30 else (0.10 if days <= 365 else 0.0)
    return cash_per_share * shares * rate
```

**关键洞察**：做正T时卖出的是 FIFO 最早的批次（通常持股 > 1 年，税率 0%），所以**做T本身不一定产生额外红利税**——但被卖掉的"免税老仓"被"新的短持仓"替代，如果后续再卖就要交税。系统必须完整模拟，不能简化。

## 6. 回测引擎设计

### 6.1 双引擎架构

| 引擎 | 用途 | 速度 | 精度 |
|---|---|---|---|
| **向量化**（polars） | 核心仓选股 + 长期持有（B1/B2/B3） | 秒级 | 不含 T+1 细节 |
| **事件驱动** | 增强层做T/波段（S0/B6） | 分钟级 | 完整模拟 T+1/分批/撮合 |

最终 S0 策略净值 = 向量化核心仓 + 事件驱动增强层，两者通过**共享持仓台账**耦合。

### 6.2 事件驱动引擎核心循环

```python
class BacktestEngine:
    def run(self, cfg, start, end):
        broker = T1Broker(cash=cfg.init_cash, cost_model=CostModel(cfg))
        for date in trading_calendar(start, end):
            # 1. 过夜：释放昨日锁定仓位
            broker.release_locked()

            # 2. 分红到账（按 ex_date）
            for div in dividends_on(date):
                broker.apply_dividend(div, date)   # 现金入账 + 计税挂账

            # 3. 日内 4 根 60min bar（做T扫描）
            for bar_time in ['10:30','11:30','14:00','15:00']:
                bars = load_60m(date, bar_time)
                signals = self.signal_engine.scan(bars, factors, broker.positions, cfg)
                for sig in sorted(signals, key=lambda s: -s.expected_net):
                    if not self.cost_gate.passes(sig, cfg): continue
                    if not self.risk.check(sig, broker, cfg): continue
                    intent = self.portfolio.to_order_intent(sig, broker)
                    broker.submit(intent, bar_price=..., allow_partial=True)

            # 4. 日终：停牌/涨跌停成交额校验、净值结算、风控检查
            broker.settle(date)
            self.nav_log[date] = broker.total_equity

            # 5. 收盘后：因子更新、次日选股池
            if is_quarter_end(date): self.rebalance(broker, date)
```

### 6.3 T1Broker 必须处理的边界

```
1. T+1：sell 数量 ≤ available（total - locked_today）
2. 涨跌停：涨停不能买、跌停不能卖（用日线的 limit_up/limit_down 标记）
3. 停牌：不成交，不产生信号
4. 最小单位：100 股整数倍
5. 现金约束：买入不得超可用现金（含 T+1 未交收的资金处理，简化为即时）
6. 分批成交：单笔成交 ≤ 该 bar 成交量的 5%（避免不可实现的假设）
7. 除权除息：ex_date 价格跳空，持仓按送转比例调整 + 现金入账
8. FIFO 出库：成本与红利税按批次精确计算
```

### 6.4 防过拟合三件套

| 方法 | 做法 |
|---|---|
| **样本外分段** | 2015-2021 训练 / 2022-2026 样本外，参数只在训练段调 |
| **Walk-Forward 前推** | 每 12 个月滚动重估参数，用未来 3 个月验证 |
| **参数敏感性热力图** | 扫描参数网格，只在**参数高原**（邻域结果稳定）取值，拒绝孤峰 |

## 7. 多基准对比体系（★ 你的核心诉求）

| 代码 | 基准 | 构建方式 | 回答什么问题 |
|---|---|---|---|
| **B1** | 集中持仓 | 股息率 Top10，等权，买入不动 | 分散是否有用？ |
| **B2** | 分散持仓 | 跨行业分散（同一选股逻辑），等权，买入不动 | **★ 增强层是否有用？** —— 最关键的对照组 |
| **B3** | 红利指数 | 中证红利 000922（+ 红利低波 H30269） | 是否跑赢被动红利？ |
| **B4** | 宽基 | 沪深300 000300 | 是否跑赢市场？ |
| **B5** | 无成本策略 | S0 的全部逻辑但**成本设为 0** | 成本吃掉了多少？ |
| **B6** | **随机交易对照（Placebo）** | 与 S0 相同的交易次数/时点密度，但**方向随机** | **★ 做T是真 alpha 还是运气？** |
| **S0** | 策略实盘 | 分散 + 增强 | 你的实际组合 |

### 判定逻辑（决策树）

```
S0 vs B2 的年化差 = 增强层毛贡献
  ├─ 差 ≤ 0              → 增强层无效，立即停止做T，退化为纯高股息组合
  ├─ 0 < 差 < 成本       → 增强层被成本吃光，需提高信号阈值或减少交易
  ├─ 差 > 成本，但 ≈ B6  → ★ 增强层收益来自"随机波动暴露"而非技术信号，无效
  └─ 差 > 成本，且显著 > B6（p < 0.05） → ✅ 增强层真实有效，可放大资金
```

> **B6 是整套设计的灵魂**。很多"做T策略"回测赚钱，只是因为它增加了交易频次、改变了风险暴露。只有跑赢"同等频次的随机交易"，才能证明信号本身有信息。

## 8. 归因与评价指标

### 8.1 收益四维拆解

```
总收益
 ├─ 股息收益      = Σ 实际到账现金分红 - 红利税
 ├─ 资本利得      = Σ 核心仓持仓的市值变动（含估值修复）
 ├─ 增强层净收益  = Σ 做T/波段已实现盈亏 - 对应交易成本
 └─ 成本          = 佣金 + 印花税 + 过户费 + 滑点 + 红利税
```
前端用**瀑布图**展示，一眼看出钱从哪来、被什么吃掉。

### 8.2 指标清单

| 类别 | 指标 |
|---|---|
| 收益 | 年化收益、累计收益、月度胜率 |
| 风险 | 年化波动、最大回撤、回撤持续天数、Calmar |
| 风险调整 | **夏普**、索提诺、信息比率 IR（相对 B2） |
| 增强层专项 | 做T次数、胜率、盈亏比、单次平均净收益、**增强贡献年化** |
| 成本 | 总换手率、成本占 NAV 比例、**成本/增强毛收益** |
| 统计 | t 统计量、p 值、置信区间、交易样本数 |

### 8.3 显著性检验

```python
# 对做T的每笔净收益序列做单样本 t 检验
from scipy import stats
t_stat, p_value = stats.ttest_1samp(trade_net_returns, popmean=0)

# 更稳健：与随机对照 B6 做配对检验
diff = np.array(s0_returns) - np.array(b6_returns)
t_stat, p_value = stats.ttest_1samp(diff, popmean=0)

# 判定门槛
if n_trades >= 100 and p_value < 0.05 and t_stat > 0:
    conclusion = "增强层显著有效"
```

> **样本量要求**：做T至少积累 **100 笔**（保守）或按回测 5 年以上，否则 t 检验功效不足，结论不可信。
