# 00 · 开发总览与全局约束

> 本套文档是 `dividend-alpha` 的**开发规格书（SPEC）**，所有参数均来自已完成的两轮实证检验，标注 `【实证】` 的为不可随意修改的硬约束。
> 实证依据：`research/REPORT.md`、`research/REPORT2.md`。

---

## 1. 系统定位

**一句话**：用「股息率历史分位」判定个股相对自身的高低贵贱，在**全 A 股**范围内轮动换股（价低买入、价涨换出），并叠加「超跌反弹事件」作为增强层，目标长期年化 ≈15%。

### 收益拆解（实证后修订版）

| 层级 | 来源 | 年化 | 验证状态 |
|---|---|---|---|
| L1 轮动层 | 股息率分位轮动 + 连续分红5年质量过滤 | **11 – 13%** | ✅ 回测 14.02%（含幸存者偏差修正后 11-13%） |
| L2 增强层 | 超跌反弹事件（20日跌>20%，持20日） | **+4 – 6%** | ⚠️ 因子级已验证（t=17.8），组合级待验证 |
| L3 减项 | 交易成本 + 红利税 + 偏差 | **−0.5%** | 实测换手 54%/年、成本 0.16%、税 0.35% |
| **合计** | | **≈ 15 – 19%** | 中枢 15% |

## 2. 硬约束清单（实证结论，不得随意修改）

### ✅ 必须保留（有正向证据）

| # | 约束 | 参数 | 证据 |
|---|---|---|---|
| H1 | **连续分红 ≥5 年**是轮动生效的开关 | `min_div_years: 5` | 无此过滤轮动 **跑输**持有 0.77%；有则 **跑赢 3.05%** |
| H2 | 分位买入阈值 | `entry_pctile_5y ≥ 60` | Q5−Q1 价差 24 月 +6.79% |
| H3 | 分位换出阈值 | `exit_pctile_5y < 30` | 分位<30 未来 24 月少赚 7.50%，t=2.95，胜率 77% |
| H4 | 股息率绝对底线 | `≥ 2.5%` | 提高到 3.5% 反而使年化 14.02%→10.75% |
| H5 | **月频**再平衡 | `monthly` | 月频 14.02% > 季频 9.72% > 半年频 10.42% |
| H6 | 最短持有 | `6 个月` | 实测中位持有 12-14 月；设为 12 月则 11.83% |
| H7 | 增强层 = 超跌反弹事件 | 20日跌>20% / 持20日 | 质量池内净超额 **+3.73%**，t=17.8，胜率 58.4% |
| H8 | 增强层只在质量池内交易 | 与核心池共用 | 全样本超额 2.95% → 质量池 **3.84%** |
| H9 | 候选池 = **全 A 股**，不设行业偏好 | — | 分位>70 的 405 只横跨消费/医药/材料/工业/券商 |

### ❌ 已证伪，禁止实现（有反向证据）

| # | 原设计 | 实测结果 | 处置 |
|---|---|---|---|
| X1 | **趋势保护**（涨过 MA60 只减半不清仓） | 年化 14.02%→**10.74%**，回撤 −24.5%→**−33.3%** | 彻底删除 |
| X2 | **红利税择时**（临近满1年推迟卖出） | 年税仅 0.35%，推迟使年化 13.14%→**12.68%** | 删除 |
| X3 | **市场温度计减仓**（整体贵时降仓） | 年化 13.11%→**11.11%**，回撤无改善 | 不实现 |
| X4 | **技术做T信号族**（RSI/布林/量价背离） | 证据远弱于超跌反弹 | 默认关闭，代码可留 |
| X5 | **降频以省成本** | 换手仅 54%/年、成本 0.16%，成本非矛盾 | 不要为省成本降频 |

## 4. 技术栈

| 领域 | 选型 | 理由 |
|---|---|---|
| 语言 | Python 3.11 | 量化生态 |
| 计算 | **polars** | 全市场因子快 5-10× |
| 时序库 | PostgreSQL 16 + TimescaleDB | 超表分片+压缩 |
| 研究态 | DuckDB + Parquet | 离线回测秒级扫全市场 |
| API | FastAPI + Pydantic | 自带 OpenAPI |
| 任务 | Celery + Redis + Beat | 重试/长任务/定时 |
| 回测 | **自研事件驱动** | 通用框架不支持 T+1/FIFO 税/分批 |
| 前端 | React + TS + ECharts + lightweight-charts | K线标注灵活 |
| 部署 | Docker Compose | 单机足够 |

## 6. 里程碑与验收门禁

| 阶段 | 内容 | 验收标准（必须全部通过才进下一阶段） |
|---|---|---|
| **P0** | 数据管道 + 月频面板 + 因子 | ① 覆盖 ≥5000 只、2008 至今；② 股息率与公开值偏差 <0.1pct；③ 数据质量校验全绿 |
| **P1** | 选股 + 向量化回测（B1-B4） | 复现实证：B2 年化 10.97%±1%、最大回撤 −28%±3% |
| **P2** | 轮动引擎 + B7/B8/B9 | **B7 年化 ≥13% 且 B7 在 B8 随机分布分位 >95%** |
| **P3** | 事件驱动引擎 + T1Broker + 成本 | ① T+1 违规 0 次；② FIFO 税单元测试全过；③ 滑点/涨停边界用例全过 |
| **P4** | 增强层（超跌事件）组合回测 | **B7+overlay 年化 ≥15% 且夏普 >0.6** |
| **P5** | Web 看板 + 告警 + 模拟盘 | 连续 12 个月模拟盘，实盘滑点 <模型 1.5× |

> **门禁**：P2 不通过 → 放弃轮动，退化为纯高股息组合；P4 不通过 → 放弃增强层，只做轮动（预期 11-13%）。

## 7. 配置即策略

所有阈值集中在 `config/strategy.yaml`，由 `da_core.config.StrategyConfig`（Pydantic）校验，**启动即验证，非法配置直接拒绝启动**。

每个回测/信号必须记录 `config_hash`，写入 `backtest_run.config_hash` 与 `signal.config_hash`，否则无法复现。
