## 1. 双引擎架构

| 引擎 | 用途 | 精度要求 |
|---|---|---|
| **向量化**（polars/numpy） | 轮动层选股与 B1-B4/B7/B9 基准 | 月频，不含 T+1 细节 |
| **事件驱动** | 增强层（超跌反弹）+ 实盘一致性校验 | 日频，完整 T+1/涨跌停/FIFO 税 |

最终 S0 = 向量化轮动仓 + 事件驱动增强仓，通过**共享持仓台账**耦合。

## 2. T1Broker（★ 正确性核心）

### 2.1 仓位账户模型

```python
@dataclass
class T1Position:
    shares_total: int      # 总持仓
    shares_locked: int     # 当日买入锁定，次日释放
    lots: list[TradeLot]   # FIFO 批次

    @property
    def available(self) -> int:
        return self.shares_total - self.shares_locked   # ★ A股 T+1 可卖数量

    def on_buy(self, n, price, date):
        self.shares_total += n
        self.shares_locked += n          # 当日锁定
        self.lots.append(TradeLot(date, price, n))

    def on_new_day(self):
        self.shares_locked = 0           # ★ 过夜释放

    def on_sell(self, n, price, date) -> tuple[float, float]:
        if n > self.available: raise T1Violation(f"T+1 violation: {n} > {self.available}")
        ...
```

**任何 `sell` 必须先校验 `n <= available`**，违规直接抛异常（测试环境）或拦截（生产）。
这是绝大多数"做T回测很赚钱"结论失真的**第一原因**。

### 2.2 必须实现的边界

| # | 边界 | 处理 |
|---|---|---|
| 1 | T+1 | `sell` 数量 ≤ `available` |
| 2 | 涨跌停 | 涨停不能买、跌停不能卖（用 `limit_up`/`limit_down`） |
| 3 | 停牌 | 不成交、不产生信号 |
| 4 | 最小单位 | 100 股整数倍 |
| 5 | 现金约束 | 买入不超可用现金 |
| 6 | 分批成交 | 单笔 ≤ 该 bar 成交量的 5% |
| 7 | 除权除息 | `ex_date` 价格跳空 + 送转调整 + 现金入账 |
| 8 | FIFO 出库 | 成本与红利税按批次精确计算 |

### 2.3 红利税（FIFO）

```python
def dividend_tax(lot, sell_date, cash_per_share, shares):
    days = (sell_date - lot.buy_date).days
    rate = 0.20 if days <= 30 else (0.10 if days <= 365 else 0.0)
    return cash_per_share * shares * rate
```

【实证】年红利税仅 **0.35%**，`fifo_sell_order: longest_first` 保留（优先卖满 1 年的批次），
但 **`full_year_bonus`（临近满年推迟卖出）已关闭** —— 实测使年化 −0.5%。

## 4. 基准体系

| 代码 | 定义 | 回答什么 |
|---|---|---|
| **B1** | 股息率 Top10 等权，买入不动 | 分散是否有用 |
| **B2** | 质量过滤 + 分散，**买入不动** | ★ 轮动 vs 不轮动的对照组 |
| **B3** | 中证红利 000922 / 红利低波 H30269 | 是否跑赢被动红利 |
| **B4** | 沪深300 000300 | 是否跑赢市场 |
| **B5** | S0 逻辑但成本 = 0 | 成本吃掉多少 |
| **B6** | 随机做T对照 | 做T是否真 alpha（旧，P4 后启用） |
| **B7** | **★ 分位轮动（无增强层）** | **轮动层本身是否有效** |
| **B8** | **★ 随机轮动**（同频率、同时点、随机换入） | **轮动选股是真 alpha 还是运气** |
| **B9** | 轮动 + 现金拖累 | 无股可换时空仓拖累多少 |
| **S0** | B7 + 增强层（超跌反弹） | 实盘组合 |

> ⚠️ B3/B4 必须使用**全收益指数**（红利全收益 H00922、300全收益 H00300），
> 否则每年 4-6% 分红会被当成下跌，导致"白赢" 4-6 个点。

## 6. 显著性检验

```python
# 月度收益差配对检验
diff = r_b7 - r_b2
t, p = stats.ttest_1samp(diff[np.isfinite(diff)], 0)
# 当前：t=1.17, p=0.243  → 尚未达显著

# 分组检验的 IC / 价差必须用 Newey-West 校正重叠窗口
def nw_t(x, lags):
    x = np.asarray(x, float); mu = x.mean(); x = x - mu; n = len(x)
    v = (x*x).sum()/n
    for L in range(1, min(lags, n-1)+1):
        v += 2*(1 - L/(lags+1)) * (x[L:]*x[:-L]).sum()/n
    return mu / np.sqrt(max(v,1e-18)/n)
```

**判定门槛**：
- 轮动层：换仓样本 ≥50 次、回测 ≥10 年、p < 0.05
- 增强层：交易样本 ≥100 笔、B7+overlay vs B7 配对 t 检验 p < 0.05
- 两者都需跑赢对应随机对照（B8 / B6）

### 决策树

```
B7 − B2 = 轮动层毛贡献
  ├─ ≤ 0                        → ❌ 放弃轮动，退化为纯高股息
  ├─ > 0 但 < 成本              → ⚠️ 降低换手、提高阈值
  ├─ > 成本，但 ≈ B8            → ❌ 收益来自"换仓行为"而非选股，无效
  └─ > 成本，且显著 > B8 (p<.05) → ✅ 有效，进入 P4 叠加增强层
```

## 7. 归因

```
总收益
 ├─ 股息收益      = Σ 到账现金分红 − 红利税
 ├─ 轮动收益      = Σ 换出实现的价差 − 对应成本
 ├─ 增强层收益    = Σ 超跌事件已实现盈亏 − 对应成本   （独立 tier 记账）
 └─ 成本          = 佣金 + 印花税 + 过户费 + 滑点 + 红利税
```

| 类别 | 指标 |
|---|---|
| 收益 | 年化、累计、月度胜率 |
| 风险 | 年化波动、最大回撤、回撤持续天数、Calmar |
| 风险调整 | 夏普、索提诺、信息比率 IR（相对 B2） |
| 轮动专项 | 换仓次数、Q5−Q1 价差、IC/ICIR、分位>70 vs <30 收益差 |
| 增强层专项 | 事件次数、胜率、盈亏比、单次平均净超额、**增强贡献年化** |
| 成本 | 总换手率、成本占 NAV、成本/增强毛收益 |

## 9. 回测回归测试清单

必须纳入 CI：

1. **T+1 违规检测**：全回测过程 `T1Violation` 计数必须为 0
2. **FIFO 税**：构造 3 个批次 + 指定卖出顺序，断言税额
3. **除权日**：断言 `ex_date` 现金入账 + 送转股数调整
4. **涨跌停**：涨停日买入应失败、跌停日卖出应失败
5. **成本**：空转（买入即卖出）应恰好损失 ≈0.30%
6. **基准复现**：§5 表格全部数字 ±1%
7. **未来函数**：随机抽取 100 个 (symbol, date)，断言因子只用 `announce_date <= date` 的数据
8. **幸存者**：断言回测池含 `delist_date` 非空的标的
