## 二、三项优化的效果

| 优化项 | 效果 | 判定 |
|---|---|---|
| ① 做T 只在持仓内 | 单笔均值 +6.81%、胜率 61.5%（原全市场版 1.43%、48.5%） | ✅ **大幅提升** |
| ② 市值 500亿→300亿 | 基准 B2 提升 | ✅ 采纳 |
| ③ 区间 2018→2015 | 基准 B2 7.30%→9.23%（样本外） | ✅ 采纳 |
| ④ **分红再投入**（本轮发现） | **+3.04%/年** | ✅★ 最大单项 |

### ① 为什么"只在持仓中做T"更强

| | 全市场扫描版 | **持仓内版** |
|---|---|---|
| 年均笔数 | 15.2 | **2.2** |
| 胜率 | 48.5% | **61.5%** |
| 单笔均值 | +1.43% | **+6.81%** |
| 年化贡献 | +1.73% | **+1.78%** |

笔数少了 7 倍，但**单笔质量提升 4.7 倍**。因为持仓内都是已通过"连续分红5年 + 300亿 + 高股息"筛选的标的，
它们超跌后的反弹确定性远高于随机标的。这印证了你"做T是寻找错误定价"的判断——**错误定价只在熟悉标的里才敢下手**。

### ④ 分红再投入：被掩盖的 3 个点

向量化回测的 `RET1` 隐含**分红即时再投资**；事件驱动版把分红变成闲置现金。
池子平均股息率 **6.58%/年**，11.8 年不复投累计少赚 **34.5 个百分点**（年化约 2.5-3%）。

**这是此前所有版本低估收益的最大单一原因。**

## 三、轮动依然失效（确认）

即使放宽到 300亿 + 从 2015 起，**轮动仍全部为负贡献**：

| 区间 | 市值门槛 | B2 | B7 | 轮动超额 |
|---|---|---|---|---|
| 2015-2026 | 无 | 12.48% | 10.72% | −1.76% |
| 2015-2026 | **300亿** | 9.05% | 7.06% | **−1.99%** |
| 2015-2026 | 500亿 | 8.06% | 8.00% | −0.06% |
| 2018-2026 | 300亿 | 7.30% | 3.38% | −3.92% |

**结论不变：股息率分位轮动在大市值段不成立，配置中保持 `rotation.enabled: false`。**

## 四、参数高原检验 ✅

围绕最优参数取 17 组邻域：

| 指标 | 值 |
|---|---|
| 年化均值 | **9.11%** |
| 标准差 | **0.59%**（极小） |
| >9% 的组合占比 | 47% |

**不是孤峰，是高原。** 最优 5 组：

| 配置 | 全期 | 样本外 |
|---|---|---|
| 30日跌20% 持40日 3×10% | 10.15% | 10.26% |
| 30日跌20% 持30日 4×8% | 9.91% | 10.34% |
| **30日跌20% 持30日 3×10%（采用）** | **9.71%** | **9.97%** |
| 25日跌20% 持30日 3×10% | 9.69% | 10.13% |
| 30日跌22% 持30日 3×10% | 9.61% | 9.73% |

采用 30/20%/30 是因为**训练期(9.83%)与样本外(9.97%)几乎完全一致**，最稳健。

### N 敏感性
N=20 最优（9.71%），N=25/30 明显下降（6.75%/5.78%），N=10/15 也偏低。

## 六、数据源改进

**同花顺 API 不可用**（网关返回 `policy_default_denied`，沙盒出口 IP 不在白名单）。

改用**东财股本变动事件流 `RPT_F10_EH_EQUITY`**：

- 覆盖 **2002 年至今**（招行最早 2002-03-27）
- 总记录 32.5 万条、651 页
- **总市值 = 总股本 × 不复权收盘价**，与东财市值报表在 2018/2023 一致率 **98%+**
- 2026 年一致率 58.7%（小盘股股本事件滞后），但**对 300亿门槛无实质影响**（大市值股仅差 2%）

## 八、结论

**9.71%（样本外 9.97%），比上一版 6.49% 提升 3.2 个点。**

提升来源：**分红再投入 +3.04%**（纠错）、区间+市值放宽（抬高基准）、做T改持仓内 +1.78%。

距离 15% 仍差 5 个点。已确认的堵点：
- 轮动在大市值段无效（−2% ~ −4%），这是当初 15% 估算的主要支撑
- 分红再投入的 7.86%/年已是收益主体，做T只是边际增强

⚠️ **最大回撤 −36.8%**（2015 股灾），波动 19.8%。这个策略不是低风险产品。
