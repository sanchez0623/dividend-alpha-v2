# 第八轮：机动换仓怎么做？（用户提问：中途没有机动换仓吗）

> 日期：2026-10-31 ｜ 问题：做T 11.8 年只触发 7 笔，如何通过"机动换仓"提升超额收益

---

## 一、先纠正一个关键误解：**T+1 不约束 30 日持仓**

"只在持仓内做T"这个约束，是**日内做T（当日买当日卖必须有底仓）**场景下的要求。
但我们的持有期是 **30 个交易日** —— T+1 只禁止"当日买入当日卖出"，**不禁止"买入新股票持有 30 天"**。

**所以扫描池从"仅持仓 10 只"扩到"全合格池 300+ 只"完全合规，且不增加任何交易限制。**

这是本次能把触发次数从 7 笔提到 181 笔的根本原因。

### ❌ 强制换仓是灾难（用户原话"机动换仓"若指这个）

| 强制换仓 | 年化 | 样本外 |
|---|---|---|
| 全池 + 每月强制换 2 只 | **−6.07%** | −12.32% |
| 仅持仓 + 每月强制换 2 只 | **0.99%** | 2.75% |
| 仅持仓 + 每季强制换 1 只 | 9.83% | 12.64% |

**核心仓强制换仓 = 剪掉赢家**，与第三轮"换出频率不能高"、第五轮"轮动失效"同源。
**不要把核心仓做成频繁轮动。**

## 三、收益分解：到底靠什么赚钱？

| 口径（30日收益） | 值 | 样本 |
|---|---|---|
| A 信号触发（真实） | 4.19% | 2,026 |
| B 同日随机换股（择时相同） | 3.01% | 2,026 |
| C 全样本（随机日+随机股） | 0.79% | 224,644 |

```
择时贡献 = B − C = +2.21%   ← 在暴跌日买入本身的价值
选股贡献 = A − B = +1.18%   ← 挑哪只暴跌股的额外价值（配对 t=24.19，显著）
总效应   = A − C = +3.39%
```

### 但组合层的配对安慰剂检验：**不显著**

| | 年化 |
|---|---|
| 不做T基准 | 9.78% |
| 真实信号（12×3%） | **11.15%** |
| 严格配对安慰剂（同日期、同笔数、标的随机）×12 | 10.43% ± 1.03% |

- 做T模块总贡献 **+1.36%/年**
- 其中**择时**（暴跌日买入，随机股也行）贡献 **+0.65%/年**
- 其中**选股**贡献 **+0.72%/年**，但分位仅 **75%**、z=0.69 → **组合层不显著**

⚠️ **交易层显著（t=24）但组合层不显著**：因为组合层只有 181 笔成交（容量受限），
且核心仓波动带来大量噪声，12 次安慰剂的标准差就有 1.03%。

## 四、结论与建议

### ✅ 采纳：机动仓（而非核心仓）的"暴跌日加仓"

| 参数 | 原 | 新 |
|---|---|---|
| `overlay.scope` | `IN_POSITION_ONLY` | **`POOL_WIDE`**（全合格池） |
| `max_concurrent` | 3 | **10** |
| `position_per_trade` | 0.10 | **0.03** |
| 触发笔数 | 7 笔/11.8年（0.6/年） | **172 笔（14.6/年）** |
| 年化 | 9.83% | **11.09%**（样本外 17.32%） |

**机动仓总暴露约 30%**（10 笔 × 3%），超过 30% 会稀释核心仓（15×2% 反而降到 10.36%）。

### ❌ 不采纳：核心仓强制换仓

任何形式的核心仓定期轮动都会大幅亏损（−6% ~ −16%/年）。

### 💡 一个简化思路（可选）

既然 **+0.65%/年只靠"暴跌日买入"就能拿到**（买什么股都差不多），
可以考虑在暴跌日直接买入**红利ETF**（免印花税、成本减半、无选股风险），
只保留小仓位做精选个股。第六轮中 ETF 替代在"仅持仓"版失败，但在"全池+暴跌日"场景未测试，值得单独验证。

## 五、诚实的边界

1. 选股贡献 +0.72%/年**在组合层未通过显著性检验**（75 分位）
2. 总贡献 +1.36%/年，其中约一半来自"择时"这一更稳健的部分
3. 最大回撤仍为 −42%（与不做T相同，机动仓未增加回撤）
4. 建议实盘运行时持续记录"信号 vs 同日随机"的配对收益，积累到 300+ 笔再下结论
