## 二、核心问题：轮动超额不是稳定 alpha

我此前报告的"轮动 +3.05%/年"，**只在一种特定池子定义下成立**。换条件就翻号：

| 区间 | 市值门槛 | 流动性过滤 | B2 | B7 | 轮动超额 |
|---|---|---|---|---|---|
| 2013-2026 | 无 | 无 | 13.84% | 11.78% | **−2.06%** |
| 2013-2026 | 无 | **3000万/月** | 10.97% | 13.14% | **+2.17%** ✅ |
| 2013-2026 | **500亿** | 无 | 6.39% | 2.83% | −3.56% |
| 2013-2026 | 500亿 | 3000万/月 | 6.39% | 2.04% | −4.35% |
| 2018-2026 | 无 | 无 | 9.54% | 6.62% | −2.92% |
| 2018-2026 | 无 | 3000万/月 | 9.02% | 5.89% | −3.13% |
| 2018-2026 | 500亿 | 无 | 6.39% | 2.83% | **−3.56%** |
| 2018-2026 | 500亿 | 3000万/月 | 6.39% | 2.04% | −4.35% |

**8 个组合里只有 1 个为正。** 一个真实有效的因子不该对"池子怎么定义"这么敏感。

### 轮动超额随市值门槛的变化（2018-2026）

| 市值门槛 | 池内股数 | B2 | B7 | 轮动超额 |
|---|---|---|---|---|
| 无限制 | 655 | 9.51% | 6.50% | −3.01% |
| 100亿 | 357 | 9.50% | 5.57% | −3.93% |
| 200亿 | 233 | 10.44% | 5.27% | −5.16% |
| 300亿 | 168 | 8.91% | 2.39% | −6.51% |
| **500亿** | **114** | **6.39%** | **2.83%** | **−3.56%** |
| 800亿 | 82 | 5.34% | 5.62% | +0.29% |
| 1000亿 | 66 | 6.07% | 7.06% | +0.99% |

**在大市值段（800亿以上）轮动略微转正，但幅度太小（<1%）且池子只有 66–82 只，样本不可靠。**

### 为什么会失效

大市值股的股息率分位**波动更慢、更平滑**，价格受基本面趋势主导。2018-2026 恰是"核心资产"行情——贵的继续贵（茅台/五粮液），便宜的继续便宜（银行/建筑）。轮动系统性地**卖掉赢家、买入输家**，这正是趋势市里最差的策略。

小市值段分位信号之所以有效，很大程度是因为小盘股的均值回归特征更强 + 流动性溢价。

## 三、增强层：因子有效，但组合兑现只有 1/3

### 因子级（大市值池内，仍然显著）✅

| 事件 | 样本 | 毛超额 | 净超额 | t | 胜率 |
|---|---|---|---|---|---|
| 30日跌>20% 持20日 | 1,775 | 2.55% | 2.25% | 9.45 | 57.2% |
| **20日跌>15% 持20日** | 2,651 | **2.48%** | **2.18%** | 11.01 | **58.1%** |
| 15日跌>15% 持10日 | 1,743 | 2.28% | 1.98% | 11.31 | 60.4% |
| 10日跌>15% 持10日 | 957 | 2.22% | 1.92% | 7.75 | 58.1% |

**超跌反弹在大市值池内依然成立**（t=11，净超额 2.18%）。这一点是可靠的。

### 组合级：只兑现 +1.73%/年 ⚠️

因子级预期 vs 实盘落差的原因：

| 落差来源 | 说明 |
|---|---|
| **事件聚集** | 大跌通常全市场同时发生，`max_concurrent=4` 会让你**只吃到最差的那几笔**（涨停/流动性差的先被卡掉） |
| 胜率下滑 | 因子级 58.1% → 组合级 **49.5%** |
| 单笔收益下滑 | 因子级 2.18% → 组合级 **0.99%** |
| 交易次数 | 理论 47 次/年 → 实际 23 次/年（资本与并发限制） |
| **成本累积** | 504 笔交易累计成本 **6.75%**（约 0.77%/年） |

事件频率（正确口径，池内平均 59 只）：20日跌15% 事件约 **47 次/年**，但你能承接的只有一半。

## 五、三个可选方向

### 方向 A：放宽市值到 200亿以下（恢复轮动）

轮动在中小市值段才有效。若接受 100–300亿：
- 池内股数 168–357 只，容量足够
- 但**这与你"大市值稳定"的诉求冲突**，且小市值波动更大

### 方向 B：放弃轮动，只做"高股息持有 + 超跌增强"（推荐）

**S1 = 5.04%**，结构最简单、逻辑最硬（超跌反弹 t=11，大市值池内可靠）。
改进空间：
- 增强层**不要设并发上限过死**，改为"按信号强度排序取前 N"，优先吃最强的
- 事件聚集时**用 ETF 替代**（510880/515180，免印花税，成本减半）
- 把 20% 的增强仓在无人触发时**放回货币/国债逆回购**，别闲置

### 方向 C：重新定义轮动信号（需要新研究）

当前"股息率分位"在大市值段失效。可尝试：
- 用**行业中性化**后的分位（剔除板块 Beta）
- 用**股息率绝对水平 + 趋势确认**替代分位
- 加入**分析师一致预期/盈利修正**

⚠️ 这些都需要重新做因子检验，且历史上 A 股大市值高股息的轮动证据本就薄弱。

## 六、必须说明的局限

1. **总市值数据仅 2018-01 起**（东财报表限制），无法回测 2013-2018 的大市值版本
2. 2018-2026 含 2018 熊市与 2021-2022 成长股崩塌，对红利策略**偏有利**，实际结果可能更差
3. 涨跌停/停牌用"单日涨跌 >9.8%"近似，未用真实停牌表
4. 滑点模型为固定 10bp，未用盘口深度
5. 无行业分类，未做行业中性化
6. 红利税按"月频近12月分红"近似，非逐笔精确
