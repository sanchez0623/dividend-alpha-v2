# 02 · UI 规格文档

> **dividend-alpha v3.1 · Forward-only**
> 行为基准：`web/prototype.html`（8 页签可交互原型）；视觉基准：`web/ui_design/01~08_*.png`
> 前端技术栈：React 18 + TypeScript + Vite + ECharts / lightweight-charts；样式用 CSS 变量，不引 UI 框架主题

## 1. 整体布局

```
┌──────────┬─────────────────────────────────────────────────────────┐
│ sidebar  │ topbar（数据日期 / 运行模式 / 本金 / 状态灯）             │
│ 216px    ├─────────────────────────────────────────────────────────┤
│          │ h1 标题 + sub 副标题                                     │
│ 品牌     │ ─────────────────────────────────────────────────────── │
│ 8 页签   │ 主内容区（卡片网格，14px gap）                           │
│ 分组：   │                                                          │
│ 监控/验证│                                                          │
│ /系统/归档│                                                          │
│          ├─────────────────────────────────────────────────────────┤
│ 底部状态 │ footer（版本 / 数据口径 / 唯一真值文档链接）              │
└──────────┴─────────────────────────────────────────────────────────┘
```

- 侧栏 `position: sticky; height: 100vh`，选中项左边 2px 青绿高亮条 + 10% 背景
- 主区左右 padding 22px；卡片网格 gap 14px
- 常用栅格：`2fr 1fr`（图表+侧栏）、`1fr 1fr`、`repeat(6,1fr)`（KPI）
- 响应式：<1200px 时 KPI 变 3 列，双栏变单栏

## 2. 设计系统（CSS 变量，逐字对齐原型）

```css
:root{
  --bg:#0B1220;        /* 页面底 */
  --card:#131C2E;      /* 卡片 */
  --card2:#101A2B;     /* 代码块 / 次级面 */
  --line:#22304A;      /* 边框 */
  --acc:#2DD4A7;       /* 主强调：正向/策略/选中 */
  --acc-dim:#1B7F66;
  --amber:#F5A524;     /* 警示/估算/预警 */
  --red:#EF6461;       /* 负向/未通过/拦截 */
  --blue:#7C9CC4;      /* 基准线/B2 */
  --text:#E8EEF7;
  --muted:#8A9AB5;
  --dim:#5C6E8C;
  --mono:"SF Mono","JetBrains Mono","Roboto Mono",Consolas,monospace;

```

| 元素 | 规格 |
|---|---|
| 页面背景 | `--bg` + 44px 细网格（rgba(45,212,167,.018)） |
| 卡片 | `--card` / 1px `--line` / radius 9px / padding 16px |

| KPI 数字 | 24px / 600 / `--mono` / letter-spacing −0.5px |
| 表格 | 12px；th 10.5px `--dim`；斑马纹；hover 青绿 5.5% |
| 数字列 | `.num` 右对齐 + `--mono` |

| 提示框 | `.callout`（琥珀）/ `.callout.g`（青绿），左边框 3px |

## 3. 数据标注规范 ★（本版本强化）

**每个数字/表格/图表必须带且仅带一个标注**，四选一：

| 标注 | 含义 | 视觉 | 出现位置 |
|---|---|---|---|
| `实时` | 生产账本当日值 | 青绿小圆点 | 总览账户、持仓、信号流水、取现当年累计 |
| `演示` | 占位，等 P4 数据管道 | 灰色 `.tag` | 持仓明细（初期）、信号流水（初期） |
| `估算` | 非精确口径 | 琥珀 `.tag` | 全收益指数、超额数字（历史） |
| `归档` | 2015-2026 历史样本 | 琥珀 `.tag` + 「只读」 | 第 8 页全部；其他页引用时 |

**实现要求**：后端每个数值响应带 `data_class` 字段，前端统一渲染标注组件，禁止前端硬编码判断。

## 5. 逐页规格

### 5.1 总览 P1

**新增琥珀提示条**（顶部，全宽）：
> 生产系统自 2026-11-05 起 Forward-only 运行。历史基线数字仅供参照 → [历史归档]

**新增「前瞻运行进度」卡片**（3 条进度条，见 §5.5 组件定义）：
- 运行天数 `1 / 1095`
- 累计净值差 `S* − B2` `+0.00%`
- 做T配对样本 `0 / 300`

**KPI 6 卡**（生产口径）：总资产 / 可用现金 / 持仓市值 / 当日盈亏 / 持仓只数 / 数据源健康。
历史 KPI（10.61% 等）**移到第 8 页**；此处仅保留一个小的「研究基线」链接卡。

其余：净值曲线（**前瞻**，起点 D0，随日增长）、今日信号列表、持仓概览前 5、数据源状态。

### 5.2 持仓 P2

10 行表格，列顺序固定：
`代码 | 名称 | 行业L1 | 银行子类 | 股息率TTM | 持仓市值 | 成本价 | 浮盈 | 持有月数 | shares_available | 状态`

- `shares_available` 列体现 T+1（`total − locked`），当日买入为 0
- 状态徽章：持有(青绿) / 观察(灰) / 超涨预警(琥珀) / 待卖出(红) / 停牌(灰)
- 行业环图：10 段等权，9 类 L1，银行子类 2 段；中心显示「10 只 · 等权」
- 卖出规则卡：硬规则 / 超涨 / 禁止项 / 排序 / 再平衡

### 5.3 信号 P3

- 表格列：`日期 | 标的 | 20日跌幅 | RSI(14) | 强度 | 预期净收益 | 成本闸 | 执行状态`
- **表头必须标注「价格口径：前复权」** 🆕（对应变更 C1）
- 成本闸徽章：通过(青绿) / 拦截(灰) / 冷静期(琥珀) / 资金不足(红)
- 右侧：参数代码块（从 config 读）+ 实证状态卡（**标注「历史样本」**）
- 实证状态文案固定：因子级净超额 +3.09%、t=11.28、B6 分位 75%、组合层不显著

### 5.4 归因 P4

- 前瞻模块贡献：样本不足时每条显示「待积累」灰色条 + 已运行天数，不显示历史数值
- 现金流拆解（实时账本）：分红到账 / 交易成本 / 红利税 / 逆回购利息
- 分年度柱状图：样本 <3 年显示占位框 + 「还需 X 天」，不显示年化

### 5.5 基准对比 P5 ★ 变更 C2：双模式状态机

#### 模式切换组件

```
[ 前瞻进度 (默认) ] [ 年化超额 🔒 ]     ← .seg 按钮组
```

| 状态 | 条件 | 行为 |
|---|---|---|
| `PROGRESS`（默认） | 任意 | 渲染 §5.5.1 三条进度条 + B1-B6 表 |
| `ANNUAL_UNLOCKED` | `n ≥ 1095` **且** `m ≥ 300` | 渲染年化超额 + B6 安慰剂分布 |
| `ANNUAL_LOCKED` | `n < 1095` 或 `m < 300` | 按钮灰显带 🔒；点击后展示拦截卡片 |

**拦截卡片文案**（固定）：
> 样本不足，暂不展示年化超额
> 还需 **{1095−n}** 天 / **{300−m}** 笔做T配对样本
> 年化超额在样本 <3 年时无统计意义 → [查看历史基准存档]

#### 5.5.1 进度条组件（新增，复用于总览与基准页）

```tsx
<ProgressBar label="运行天数" value={n} target={1095} fmt={(v)=>`${v} / 1095 天`} />
<ProgressBar label="累计净值差 S*−B2" value={diffPct} target={null}
             fmt={(v)=>`${v>=0?'+':''}${v.toFixed(2)}%`} neutral />
<ProgressBar label="做T配对样本" value={m} target={300} fmt={(v)=>`${v} / 300 笔`} />
```

- 轨道 `height 15px`、`--card2` 底、radius 3
- 填充色：达成青绿 / 未达成青绿 60% 透明 / 负向红
- 右侧等宽数字
- `neutral` 型（净值差）无 target，用居中零轴双向条

#### 5.5.2 B1–B6 状态表（两模式共用）

`基准 | 定义 | 当前净值 | 状态`，状态：运行中 / 启用 / 估算 / 未通过。
B6 行固定标「未通过」（历史），但**前瞻样本另起一列**显示 `m / 300`。

#### 5.5.3 API 守门（后端硬约束）

```python
def get_benchmark_view(mode: str) -> BenchmarkView:
    n = ledger.running_days()
    m = ledger.paired_trade_count()
    if mode == "annual" and (n < 1095 or m < 300):
        raise SampleInsufficient(n=n, m=m, need_days=1095-n, need_trades=300-m)
    # 样本不足时，响应中【不得包含】任何 annual_excess_* 字段
```

> 前端隐藏不算守门，**API 层必须不返回年化超额字段**（验收 A3 用接口测试验证）。

### 5.6 取现流水 P6

- 顶部 3 个实时数字：当年累计税前分红 / 应取 30% / 距 12 月最后交易日 X 天
- 规则 YAML 代码块（含 `idempotency_key: (year, account_id)`）
- `execution_log` 表：`年份 | 执行时间 | 应取 | 实取 | 兑现率 | 幂等键 | 状态`
- 方案对比表（**标注「历史样本」**）
- 历史逐年流水 → 链接归档页，本页不重复展示

### 5.7 配置 P7

- 参数只读代码块（`config/strategy.yaml` 渲染）
- 8 条已知限制表
- 数据源状态卡 🆕（**v3.1 共 4 行**）：`同花顺 fuyao（主）· 白名单状态` / `AKShare 1.20.35（备）· 接口核实状态` / `baostock（串行兜底）· 待实测` / `东财 push2his（最后兜底）· 已知 502`；另列 `复权因子` / `全收益指数` 两项能力状态，每行状态圆点。**仅不得出现 tushare**
- 底部 3 小卡：`基线校验通过` / `配置哈希` / `最后更新时间`

### 5.8 历史归档 P8 🆕 变更 C3

**必须元素**（缺一不可）：

1. **顶部琥珀横幅**，全宽、左边框 3px：
   > ⚠️ 以下数字来自 **2015-01 ~ 2026-10 历史样本**，不是已验证的将来收益；
   > 生产系统自 **2026-11-05** 起 Forward-only 运行。
2. 标题「历史回测归档」+ 副标题「研究存档 · 只读 · 不代表前瞻业绩」
3. 右上角 `.tag`：「只读 / 归档快照」
4. **5 个 KPI**：年化 10.61% / 样本外 15.61% / 期末 931.9 万 / 夏普 0.39 / 最大回撤 −42.5%
   —— 每张卡下方小字「历史样本」
5. 历史净值曲线（S\* / B2 / 沪深300价格指数，2015-2026，可切全期/近3年/样本外，悬停看逐月）
6. 模块贡献横条 + 分年度 S\* vs B2 柱状图 + 逐年取现流水表
7. 「10 轮实证结论摘要」列表（轮动证伪 / 增强层不显著 / 分红是主体 / 取现方式对比 / 15% 下修）
8. REPORT1~11 索引表（名称 / 主题 / 状态）
9. 页脚：「研究脚本与缓存归档于 `research/`，不进生产镜像」

**本页数据源固定为 `web/data.json`，只读，禁止任何写操作。**

## 6. 交互清单

## 7. 可访问性与健壮性

- 图表提供 `<title>` / 图例文本，不依赖纯颜色传达语义（配合 +/− 号与标签）
- 数值为 `null` 时统一渲染 `—`，禁止 `NaN` / `undefined`
- 加载态显示骨架卡片，错误态显示 `数据暂不可用` + 重试按钮，不白屏
- 所有金额用 `toLocaleString('zh-CN')`，万元单位统一 `fW()`
