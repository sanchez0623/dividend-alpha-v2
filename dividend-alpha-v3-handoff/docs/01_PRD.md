## 1. 产品定位

### 1.1 一句话

一套 A 股高股息组合的**准实时前瞻验证系统**：按锁定参数持有并动态管理 10 只大市值高股息股，
叠加实验性的超跌反弹增强，同时并行跑 6 条基准，持续证伪自己。

### 1.2 用户原始诉求 → 现状映射

| 用户诉求 | 本版本的处理 | 说明 |
|---|---|---|
| 长期 10-20 年持有高股息、跨行业分散 | ✅ 核心仓 N=10 等权、L1≤1、银行子类≤2 | 行业约束实测 +1.81%/年（历史样本） |
| 技术指标做T / 中级波段获取超额 | ⚠️ 保留但降级为 `experimental` | B6 安慰剂未通过，组合层不显著；从今天起重新攒样本 |
| 长期年化 15% | ❌ 已下修 | 历史样本 10.61%（含取现），非承诺收益 |
| 动态换仓（涨贵了换到便宜的） | ❌ 已证伪并永久关闭 | 4 次不同形式验证均为负贡献 |
| 多个对比基准确认有效性 | ✅ B1–B6 + 配对安慰剂 | 本系统真正的重心 |
| 每年年底取当年分红 30% | ✅ 已锁定 | 见 §4.3 |
| 日线/小时线准实时监控 | ✅ 日线为主，60min 可选 | 见 `03_ARCHITECTURE.md` |
| 从 2015 年开始 | 🗄 归入只读归档 | 生产改 Forward-only，见 §2 |

### 1.3 运行模式：**Forward-only**（不可切换回历史模式）

- 生产系统起始日：**2026-11-05**
- 生产系统**不复现** 2015-2026 历史回测；`research/` 是只读研究归档
- 生产库从第一天起记录：每日净值、持仓、信号、成交、分红、取现、6 条基准
- **系统性质**：从「跑过 11.8 年的策略」变成「从零积累的前瞻实验」

### 3.1 总览（P1）

- 顶部**琥珀提示条**：「生产系统自 2026-11-05 起 Forward-only 运行；以下历史基线数字仅供参照，见历史归档」
- 「前瞻运行进度」卡片：运行天数、累计净值差、做T配对样本数（三条进度条）
- 账户状态：总资产、可用现金、持仓市值、当日盈亏
- 今日信号列表（含成本闸状态）
- 持仓概览（前 5 只）
- 数据源状态灯

### 3.2 持仓（P2）

- 10 行表格：代码 / 名称 / 行业(L1) / 银行子类 / 股息率TTM / 持仓市值 / 成本价 / 浮盈 / 持有月数 / `shares_available`（T+1）/ 状态
- 状态标签：持有 / 观察 / 超涨预警 / 待卖出 / 停牌
- 行业分散环图（10 只、9 类 L1；银行按子类占 2 席）
- 卖出规则卡（硬规则 + 浮盈>50% 清仓）

### 3.3 信号（P3）

- 信号流水：日期 / 标的 / 20日跌幅 / RSI(14) / 强度 / 预期净收益 / 成本闸 / 执行状态
- **所有价格类字段必须标注「前复权」**
- 参数代码块（从 config 读，不硬编码）
- 实证状态卡：因子级 t=11.28 / B6 分位 75% / 组合层不显著 —— **标注「历史样本」**

### 3.4 归因（P4）

- 前瞻模块贡献：样本不足时显示「待积累」占位条 + 已运行天数
- 现金流拆解（实时账本）：分红到账、交易成本、红利税、逆回购利息
- 分年度柱状图：样本 <3 年显示占位与进度，不显示年化

### 3.5 基准对比（P5）★ 本轮变更 C2

**双模式，可切换**，状态机见 `02_UI_SPEC.md §5.5`：

| 模式 | 条件 | 展示 |
|---|---|---|
| **A 前瞻进度（默认）** | 任意 | 运行天数 `n / 1095`、累计净值差 `S*−B2`、做T配对样本 `m / 300` 三条进度条 + B1-B6 状态表 |
| **B 年化超额** | `n ≥ 1095` 且 `m ≥ 300` | 相对沪深300全收益 / 红利基准全收益的年化超额 + B6 安慰剂分布 |
| **B 被拦截** | `n < 1095` 或 `m < 300` | 灰显切换按钮 + 「样本不足，暂不展示年化超额（还需 X 天 / Y 笔）」+ 跳转历史归档链接 |

**硬规则：样本 <3 年时，代码层面禁止计算并渲染任何"年化超额"字段**，不是仅前端隐藏。

历史归档链接：B 模式下仍可点「查看 2015-2026 历史基准」跳到第 8 页，且明确标注为存档。

## 4. 核心业务规则（锁定，来自 `config/strategy.yaml`）

### 4.1 选股与持仓

```yaml
universe:   连续现金分红 ≥5 年 · 总市值 ≥300 亿 · 股息率TTM ≥2.5% · 排除 ST / 退市整理
portfolio:  N=10 等权 · core_ratio 0.90 · 同 L1 行业 ≤1
            银行按 国有大型/股份制/城商/农商 四级细分，视为不同类，每子类 ≤2
selection:  股息率 TTM **绝对值降序**取前 10（禁止按分位排序）
rebalance:  月频，仅补仓到 N，不主动换股
```

### 4.2 卖出

| 类型 | 条件 | 动作 |
|---|---|---|
| 硬规则 | 股息率TTM <1.5% / 分红中断 / 持有满 5 年 | 全部卖出 |
| 超涨 | 相对成本浮盈 ≥50% | **一次性清仓**（分批挪仓已证伪） |
| 禁止 | 轮动 / 条件换仓 / 强制换仓 / 趋势保护 | — |

### 4.3 分红与年度取现 ★

```yaml
dividend_reinvest:  年内到账分红 100% 按持仓市值权重再投（min_cash_ratio 0.02, lot 100）
dividend_withdraw:
  mode: annual
  timing: 每年 12 月最后交易日（盘后）
  base: 当年累计【税前】现金分红（核心仓 + 机动仓）
  ratio: 0.30
  shortfall_policy: cash_only        # 可切 sell_to_cover（100%兑现，年化差 0.04%）
  idempotency_key: (year, account_id)
  skip_incomplete_year: true         # 进行中的年份不取
```

**幂等是硬要求**：重复调度不得重复取现，必须写 `execution_log`。

### 4.4 增强层（实验性）

```yaml
overlay:
  enabled: true
  experimental: true                # ★ 不得当作收益来源
  scope: POOL_WIDE                  # 全合格池（T+1 不约束 30 日持仓）
  trigger: 20日跌幅 ≥12% 且 RSI(14) <25   # ★ 必须基于【前复权价】
  holding_days: 30
  rank_by_strength: true
  max_concurrent: 12
  position_per_trade: 0.03          # 机动仓总暴露 ≈30%
  cooldown_days: 5
  capital_guard: amt + cost ≤ cash × 0.98
```

### 4.5 成本闸（不可绕过）

- 单笔往返成本 ≈ 0.30%（个股）：佣金 0.025% 双边(min 5 元) + 卖出印花 0.05% + 过户 0.001% + 滑点 0.10% 双边
- 信号生成条件：`expected_net ≥ 0.8%` **且** `expected_net ≥ 3 × 往返成本`
- 红利税：≤1月 20% / 1月~1年 10% / >1年 0（FIFO 批次）
- 闲置现金按国债逆回购 2%/年计息

### 4.6 T+1 账户模型（正确性地基）

`shares_total / shares_locked / shares_available` 三字段；`sell` 必须校验 `n ≤ available`。
当日买入标记 locked，收盘 `settle_eod()` 解锁。FIFO 批次用于红利税档位。

## 6. 已证伪清单（禁止实现）

> 证据见 `docs/legacy/REPORT3/5/6/9/10/11.md`。重复实现视为回归缺陷。

| 设计 | 实测结果 |
|---|---|
| 股息率分位轮动 | 8 种池子定义仅 1 种为正；大市值段 −2%~−4%/年 |
| 条件换仓（高位+低股息率才换） | 净贡献 ≈0，且破坏做T（+1.36% → −0.02%） |
| 核心仓强制换仓 | 年化 −6.07%，样本外 −12.32% |
| 定向挪仓 / 分批挪仓 | 样本外崩（1~5%）；一次性清仓最优 |
| 按分位排序换入 | 3.21% vs 按股息率绝对值 9.76% |
| MACD 金叉 | 净超额 −0.36%，t=−0.66 |
| 趋势保护 / 让利润奔跑 | 14.02% → 10.74%，回撤反而恶化 |
| 市场温度计减仓 | 收益降 2 个点，回撤未改善 |
| 红利税择时卖出 | 年化 13.14% → 12.68% |
| ETF 系统性替代 | 6.52% → 5.10% |
| 年内预留取现 | 9.32%，且兑现率仍不足 |
| 每笔即时抽 30% 分红 | 做T失效（+1.36% → −0.03%） |
| 非等权（股息率平方加权） | 10.39% → 10.23%（N=10） |
| N=20 | 收益低于 N=10；且事件驱动有 N 相关摩擦 |
| 流动性门槛（月成交额） | 提高门槛会砍掉策略收益，300 万无需此限制 |
