# 分红捕获策略（DC）· 规格与运行说明

> 版本：1.0 ｜ 与 S\* 高股息组合**并行**运行 ｜ 参数真值：`config/strategy_dividend_capture.yaml`

---

## 1. 策略定义（用户口径，冻结）

| 项 | 规则 |
|---|---|
| 选股池 | A 股总市值 ≥ **500 亿**、非 ST/退市 |
| 股息率 | TTM 现金分红 / 买入日不复权收盘价 ≥ **6%** |
| 趋势 | 默认 **非下跌**：`close > MA120`；优先"上涨 + 回调"：`close > MA60 > MA120` 且 RSI14∈[35,70]、20 日跌幅∈[-12%,+3%] |
| 买入 | 除权日前第 **5 个交易日**收盘 |
| 卖出 | 除权日 + **30 个自然日**后的首个交易日收盘 |
| 持仓数 | **1 只**（持仓期间到达买点的其他候选放弃，计入 skipped） |
| 分红 | 除权日按 `dps × 持股数` 记税前现金分红；送股按 `per_share_bonus` 扩股 |
| 红利税 | 卖出时按实际持有天数：≤30 天 20%、31–365 天 10%、>365 天 0%（本策略约 37 天 → 10%） |
| 取现 | 卖出时提取 **净分红（税后）的 30%**；余额连同本金滚入下一只 |
| 成本 | 复用 `config/strategy.yaml` 的 cost 段（佣金/印花/过户/经手/证管/滑点） |
| 现金利息 | 不计息（与 S\* 净值口径一致） |

> 用户原话"一年可以分红 10 次"在 **单标的 + 30 天持有** 下不成立：A 股分红集中在 6–7 月，
> 历史实际可捕获约 **4–6 次/年**，其余候选因持仓重叠被放弃。回测与页面都会如实列出
> `捕获次数` 与 `放弃数`。

## 2. 与 S\* 的隔离（硬约束）

- 独立配置：`config/strategy_dividend_capture.yaml`，**不修改** `config/strategy.yaml`，
  因此 S\* 的 `config_hash`、`signal_pair`、`factor_daily` 幂等键不变。
- 独立账户：`account_id = DC`；独立策略净值：`strategy_id = DC`。
- 独立表：`dc_cycle`（周期/税/取现）、`dc_universe_cache`（周度池快照）。
- 复用表：`Account/Position/Lot/Order/Fill/DividendEvent/DailyNav`，全部按 `account_id=DC` 隔离。
- 不打开 `rotation.enabled`；不改变 S\* 的选股/卖出/年度取现逻辑。
- 生产闭环：`scripts/worker_once.py` 先跑 S\*、再跑 DC；DC 失败只回滚自身，S\* 已提交不受影响。

## 4. 数据口径

- **股息率 TTM**：`corp_action` 中 `(ex_date-365, ex_date]` 的 `dps` 合计 ÷ 买入日 `raw_close`；
  分子分母同口径（不复权）。含本次即将除权的分红。
- **技术指标**：`price_daily.adj_close`（生产同款前复权，`build_adj_factor`）。
- **市值**：线上用东财快照 `market_cap`；回测用"当前股本 × 历史不复权价"估算，
  并按 `per_share_bonus` 从当前向历史反推股本（近似，报告披露）。
- **交易日历**：线上用同花顺 `calendar/trading-days`；回测用 000300 日历。
- **除权事件**：同花顺 `corporate-actions/adjustment-factors`；不采用合成源。
- **价格**：买入/卖出均用当日**不复权收盘**（盘后闭环），DC 净值 = 现金 + 股数 × 不复权价。

**优化方向：条件卖出（用户方向 1）——全部劣于固定 30 天**

| 变体 | CAGR | 总财富 | MDD | 胜率 | 平均持有 |
|---|---:|---:|---:|---:|---:|
| 固定 ex+30（base） | +0.36% | +3.97% | -31.00% | 50.0% | 38.2 天 |
| 固定 ex+22 交易日 | -2.76% | -26.18% | -48.07% | 37.8% | 40.8 天 |
| 填权达标就走 | +0.56% | +6.24% | -34.60% | 55.9% | 27.1 天 |
| 3 日不填权就走 | -4.07% | -37.15% | -47.08% | 37.6% | 12.2 天 |
| **-3% 止损（买入价，除权日跌破也砍）** | **-3.88%** | **-36.47%** | **-53.5%** | **16.5%** | 14.0 天 |
| -3% 止损（除权日收盘） | -1.98% | -19.49% | -46.58% | 32.1% | 29.2 天 |
| 收益覆盖红利税就走 | -1.11% | -11.35% | -39.40% | 54.3% | 19.6 天 |
| 组合（买价止损优先） | -4.37% | -39.84% | -47.21% | 28.2% | 7.3 天 |

- **早卖 → 20% 红利税**已量化：买价止损平均持有 14.0 天，64/79 笔 ≤30 天卖出，实际税率 **17.9%**（base 10.0%），多缴税约 34.5 万；3日不填权/组合全部 20% 档，多缴 50–60 万。
- 除权日触发止损时当日仍先拿税前分红、按实际持有天数扣税，成交价=当日 close；同日 stop 与 fill 同时满足时 stop 优先。
- **结论：条件卖出不上线。**

**优化方向：选池（用户方向 2）——300亿打分名义最好，但高度集中**

| 变体 | CAGR | 总财富 | MDD | 捕获 | 胜率 |
|---|---:|---:|---:|---:|---:|
| cap300_score + 固定30天 | **+10.23%** | +187.42% | -24.70% | 61 | 52.5% |
| cap500_score + 固定30天 | +3.55% | +45.91% | -38.11% | 55 | 56.4% |
| cap300 硬筛 + 趋势硬筛 | -1.66% | -22.26% | -34.70% | 50 | 44.0% |
| cap_any_score（纯打分） | +1.09% | +33.57% | -52.52% | 72 | 45.8% |
| 填权 × cap300_score | +2.19% | +26.43% | -28.61% | 79 | 54.4% |
| 填权 × cap500_score | +3.17% | +40.25% | -26.93% | 67 | 55.2% |

- `cap300_score` 的 score = `yield + 0.5%×(市值≥500亿) + 0.5%×趋势分`（上涨+回调=1/上涨=0.5/非下跌=0/下跌=-0.5），市值≥300亿硬筛、趋势不硬筛。
- **集中度警告**：top1 交易=三七互娱 2024-09-04 +41.2% / +216.5 万（2024-09 政策行情 beta）；去掉 top1/2/3/5 后总财富收益 +187% → +115% / +84% / +54% / +5%；2021 起子样本去掉 top2 即转负（-5.7%）；中位单笔仅 +0.11%。
- **结论：cap300_score 只能作为研究候选，需 paper-trade + 分散到 3 只，不作为上线依据；本交付不擅自替换生产规则。**

**关键结论**

1. 用"当时市值"修正后，用户原规则 10.84 年**总财富 +3.97%、CAGR 0.36%**，账户净值 **-45.10%**；旧口径 +20.31% 是幸存者偏差抬高的。
2. **"一年 10 次"不成立**：单标的 + 除权后 30 天，实际 **4.24 次/年**。
3. 收益结构：税前分红 545.3 万，但价格损益 -478.8 万 + 红利税 54.5 万 + 成本 21.1 万 → 净损益 -135.3 万；**除权缺口基本没回补**。
4. **近期更差**：2018 起 CAGR -3.85%，2021 起 -3.91%；正收益仍只来自 2016/2017。
5. **条件卖出（含买价 -3% 止损）全部劣于固定 30 天**：早卖把红利税从 10% 拉到 20%，且除权日机械止损胜率仅 16.5%。
6. **300亿+打分名义 +10.23%，但依赖极少数交易**，不能作为上线依据；生产建议保持原规则。

> 回测是 2015–2026 历史样本口径，已用买入日当时总股本×当时不复权价做 PIT 选池；仍有退市股早期分红缺失、ST 当前状态、粗筛 200 亿、股本变动日级时点差、涨跌停/流动性未建模等残余偏差；**不代表未来收益**，不构成投资建议。

## 6. 生产运行

### 6.1 每日闭环 `src/da_worker/dividend_capture_close.py`

1. 周度（周一或缓存为空）刷新全市场 ≥500 亿池 + 除权事件；
2. 取交易日历；只对"今天就是买点"的候选 + 当前持仓抓近 180 天日线；
3. 除权日税前分红入账（税递延到卖出）；送股扩股；
4. 到除权+30 天 → 卖出，扣红利税 + 提取净分红 30%；
5. 空仓且今天有买点 → 按趋势/股息率/市值排序买一只；
6. 写 DC 净值 + `execution_log`（幂等键 `{asof}:DC`）。

### 6.2 入口

```bash
# 本地/服务器容器内
python scripts/worker_once.py 2026-11-06     # S* + DC 同时跑
python scripts/dc_backfill.py 2026-11-05 2026-11-07
```

cron 沿用现有 `scripts/cron_worker.sh`（工作日 17:00），无需新增 crontab。

## 7. 已知限制

1. **退市股残余偏差**：退市清单 256 只，成功纳入 254 只；东财 F10 分红方案仅最近 10 条公告（约 5 年），晚退市股票较早除权事件可能缺失 → 方向是低估损失。
2. **ST/退状态**：按当前状态剔除，未做历史 PIT 的 ST 状态 → 方向不确定。
3. **粗筛**：用当前股本估算 max 历史市值 ≥200 亿（500 亿的 2.5 倍安全边际）筛选抓取对象，理论漏筛概率低但非零；北交所不在池内。
4. **股本 step function**：用变动日期做阶梯，存在几天级时点差；99.95% 候选用历史总股本，9 只早期退市无股本记录直接不合格。
5. **红利税/取现**：按法定档位、卖出时结算；实际券商代扣与批次可能有差异。
6. **"10 次/年"不成立**：单标的 + 30 天持有 + 6–7 月集中 → 约 4–6 次/年。
7. **半年度分红**：TTM 股息率≥6% 不代表本次除权能拿到 6%；页面显示"事件 dps / TTM dps"。
8. **执行假设**：盘后收盘价成交、100 股整数手、停牌顺延、不建模涨跌停冲击与流动性。
9. **回测≠未来**：站点所有历史数字均标记"归档·只读·不代表未来"。
