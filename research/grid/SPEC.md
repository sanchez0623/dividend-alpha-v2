## 1. 目标

回答：**对 S* 当前 10 只持仓，做「70% 核心买入持有 + 30% 价格 2% 网格」，历史 2016-2026 是否产生
稳定超额？相对 100% 买入持有 / 70% 核心+30% 现金，超额从哪来（网格交易 P&L / 现金拖累 / 成本 / 税）？**

⚠️ **选择/幸存者偏差披露（必须与结果一起读）**：这 10 只是 **2026 年选出的当前持仓**，用它们回溯 2016

**不是** S* 历史策略的复盘，也不能外推为「任意 10 只」或「未来」的网格收益。

## 3. 资金与网格

### 3.1 主口径（symmetric + trailing + 2%）

- 每只 30 万：**70% 核心 = 21 万买入持有** + **30% 网格 = 9 万**。
- 网格 sleeve 初始 **50% 股票（约 4.5 万）+ 50% 现金（约 4.5 万）**。
- **每格 = 10% sleeve（约 0.9 万）× 100 股整数手**：`unit_shares = floor(0.10 × grid_sleeve / 首日收盘 / 100) × 100`；
  每格成交股数固定为 `unit_shares`。
- **参考价 trailing**：初始 = 首个可交易日收盘；每次成交后参考价 = 成交价。
  - 收盘 ≤ 参考价 × (1 − step) 且库存 < 10 格 且现金足够 → 买入一格，成交价 = 当日收盘；
  - 收盘 ≥ 参考价 × (1 + step) 且存在 T+1 可卖批次 → 卖出 FIFO 一格，成交价 = 当日收盘；
  - **每只每日最多成交一格**；停牌无 bar 跳过（不交易，估值用最近收盘）。
- 库存边界：symmetric 允许 0 ~ 10 格（0% ~ 100% sleeve 股票）。
- **除权除息调整**：除权日参考价/锚价按 `(ref − dps) / (1 + bonus)` 调整，避免把除权跳空当成 2% 价格波动；
  送股时网格单元股数同比例扩大（保持单元金额稳定）。除权日本身不因分红/送股触发网格。

## 4. 会计（所有变体同一会计）

- **成本**：`src/da_core/cost.py::buy_cost/sell_cost`，参数读 `config/strategy.yaml` cost 段
  （佣金万0.5 min5、印花税万5 卖出、过户费万0.1、经手费万0.341、证管费万0.2、滑点 5bp）。
- **红利**：
  - 核心批次：除权日按 `dps × 股数` 收到现金；**税收 0%**（核心持有至 >1 年；Lead 冻结口径），入 core 现金。
  - 网格批次：除权日按 `dps × 股数` 收到**税前**现金入 grid 现金；卖出时按 **FIFO 批次实际持有天数**扣税：
    ≤30 天 20% / 31~365 天 10% / >365 天 0%。
  - 送股：`per_share_bonus` 扩股、成本价除权（核心与网格批次都按比例调整）。
- **现金**：不计息；核心红利入 core 现金（不再投），网格红利入 grid 现金（可继续网格）。
- **T+1**：卖出仅限买入日 < 卖出日的网格批次；买入当日不可卖。
- 100 股整数手；涨跌停/流动性不建模（披露）。

## 5. 指标

- 组合：总财富、CAGR、NAV、年化波动、Sharpe(rf=0)、MDD、Calmar；期末现金/权益。
- 网格：成交笔数、笔数/年、单笔均值、总成本、总已实现价格 P&L、grid 分红/税（含期末递延税）、
  最大 inventory（格）、暴露比例（股票市值/总权益 日均）、换手率、网格胜率（FIFO 配对、按价格差）。
- 超额：
  - vs `core70_cash30` = **网格 sleeve 净 P&L** = 网格分红 + 网格价格 P&L（已实现+未实现） − 成本 − 税（含递延）；
  - vs `hold100` = 上述网格净 P&L + **30% 现金拖累**（`W_core70_cash30 − W_hold100`）。
- 分年度、2021 子样本、最好/最差年份。
- 期末递延红利税：未卖出的网格批次按截至末日的持有天数计提，作为负债从净值中扣除（`final_wealth_net`）。

## 6. 验收断言（`verify.py`，28 项）

- 数据：10 只日线/事件齐备、价格为正、事件有序、输入 SHA256 与 summary 一致。
- 成交：成交日=交易日且当日有 bar；成交价=当日不复权收盘；金额=价×股数；100 股整数手；
  费用逐笔用 `cost.py` 复算；卖出税按 FIFO 批次持有天数复算；T+1；trailing 触发条件成立。
- 独立重放：用「初始建仓 + 逐笔成交 + 除权事件（分红/送股）+ 费用 + FIFO 税」独立重算每只期末现金/
  持仓/权益，与引擎逐只一致；期末 = 初始 + 价格损益 + 分红 − 费用 − 税。
- 可复现：同输入两次回测 nav/trades 哈希一致，且等于 summary 记录值。
- 超额分解恒等式：excess(vs core70) == grid_net；excess(vs hold100) == grid_net + 现金拖累。
- 基准无网格成交；2021 子样本期末权益复算一致。

## 7. 局限（必须与结果一起读）

1. **选择/幸存者偏差**（最重要）：10 只是 2026 年当前持仓，2016 回溯会系统性高估「买入持有」收益，
   从而夸大 30% 现金的拖累；同时网格收益也可能被这些标的的特定波动路径放大。不能外推到未来或其它标的。
2. 网格参数（2%）未做样本外优化；1.5%/2.5% 仅为敏感性。
3. 每日收盘单点成交，不建模盘中触发顺序；成本已含 5bp 滑点。
4. 除权日参考价按 `(ref−dps)/(1+bonus)` 调整、送股扩单元股数——这是一致性处理，不同实现会有差异。
5. 核心红利按 0% 税（持有>1年）；若按实际持有天数，仅 2016 年首年分红应缴 10%（影响 <0.1pp/年）。
6. 未平仓网格批次的递延税按期末持有天数计提；实际卖出时点不同会有小差异。
7. 回测≠未来；历史结果不代表未来收益。
