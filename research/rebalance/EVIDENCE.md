## 1. legacy 实验口径判定

### 1.1 结论（一句话）

`月频 14.02% > 季频 9.72% > 半年 10.42%` 是 **B7「股息率分位轮动 + 连续分红≥5年质量过滤」组合的换股/再平衡频率参数扫描**（`REPORT.md:74,78,79`；`dev/03-backtest.md:132-135,213`），**不是**"同一篮子等权重置（volatility harvesting / rebalancing premium）"实验。

三种容易混淆的机制必须先分开：

| 机制 | 定义 | legacy 对应 | 本 SPEC 对应 |
|---|---|---|---|
| **换股轮动** | 卖出股息率 5 年分位低（涨贵了）的股票、买入分位高（便宜）的股票，**成分发生变化** | B7（`dev/03-backtest.md:102`） | 不做（rotation 已冻结：`config/strategy.yaml:37`） |
| **单边补仓** | 每月只把低配标的补到 1/N，**不卖超配** | v3.1 生产：`rebalance: monthly 仅补仓到 N，不主动换股`（`01_PRD.md:156`；`config/strategy.yaml:28`；`IMPLEMENTATION.md:66`） | 本 SPEC 不含此变体 |
| **双边等权重置** | 卖超配 + 买低配，回到 1/N，**成分不变** | legacy 未见干净的 A/B | `m_last / q / s / a / band5 / band10`（`SPEC.md:68-80`） |

**口径判决**：legacy 的频率实验对象是"换股轮动"；频率调整同时改变"换股次数"与"权重重置次数"，**无法分离出等权重置溢价**。用这组数字回答"再平衡能不能赚钱"属于口径混用。

### 1.3 为什么不能拿它当本研究先验（4 条硬理由）

**（a）成分可变，频率效应不可分解。** B7 每次"再平衡"会换股：中位持有分别 12 / 24 / 26 个月，年换手 54% / 37% / 29%（`REPORT.md:74,78,79`；`dev/03-backtest.md:132-135`）。频率越低，换股次数与信号兑现越少——"降频"同时改变"换股"和"权重重置"两种效应，无法归因给再平衡。

**（b）legacy 没有干净对照，甚至"买入不动"口径存疑。** `dev/03-backtest.md:97` 定义 B2 为"质量过滤 + 分散，**买入不动**"，但 `REPORT.md:71-72` 的 B2 行却报"**年换手 48%**、年成本 0.14%、**中位持有 12 月**"——真正的 buy-and-hold 应 ≈0 换手、持有期≈全样本。**推断（非文档明示）**：该对照臂很可能内嵌了周期性的等权重置/再构成，或"换手"口径未说明。无论哪种，legacy **既没有"同篮子 hold vs 双边修剪"的 A/B，也无法把 B7−B2 解释为"再平衡溢价"**。这是本研究的证据缺口，不是先验。

**（c）频率结论本身不显著、且与因子期限自相矛盾。**
- B7−B2 点估计 +3.05%/年，但 **t=1.17，p=0.243**，未达预设门槛（`REPORT.md:84`；`dev/03-backtest.md:148-150`；`rotation-engine.md:333`）；
- 预设门槛是"换仓 ≥50 次、≥10 年、**p<0.05**、且必须显著跑赢 B8"（`dev/03-backtest.md:161-164`）——首轮不达标；
- B8 随机轮动均值 **9.58%**（区间 7.12–12.09%），**低于 B2 的 10.97%**（`dev/03-backtest.md:130,136`；`REPORT.md:72,80`）→ 即"换仓行为本身"约 −1.4%/年；B7 的正差来自"选择"（`rotation-engine.md:334` 的 98.3 分位），而"选择"随后在大市值段翻号（见 §1.4）；
- 报告自己说分位因子"3–6 个月几乎没有信息，24 个月才形成可靠信号……轮动节奏不该是月度……而应是 1–2 年一轮"（`REPORT.md:38`），却用月频最优来否证降频（`:109-112`）——**内部不一致**；
- 相邻频率噪声极大：`REPORT9.md:45-53` 网格里"5 月频 8.01% vs 6 月频 16.12%"，相邻频率差 8 个点，30 组标准差 2.67%，`:49-55` 判"断崖式参数敏感，不可信"；换入排序从"分位"改成"股息率绝对值"就从 3.21% 翻到 9.76%（`REPORT9.md:59-70`）。
  → 频率排序（尤其"月频最优"）**不能**外推到"等权重置频率"。

**（d）对象不同。** B7 是换股；本 SPEC 的 `m_last` 是"同一篮子内卖超配、买低配"（`:68-80`），不改变成分；v3.1 生产更是"只补仓、不卖超配"（`01_PRD.md:156`；`config/strategy.yaml:28`）。三者语义不同、收益来源不同，不能互为替代。

## 2. 理论：等权再平衡溢价（volatility harvesting / rebalancing premium）

### 2.1 来源与公式

再平衡溢价不是选股 alpha，而是**组合权重再平衡带来的几何收益增量**（diversification return / rebalancing premium）。

- 两资产（Bernstein 1996，§3 #1）：
  ```
  RB12 ≈ x1·x2[ σ1·σ2·(1-ρ12) + (σ1-σ2)^2/2 ]
        = x1·x2( Var1/2 + Var2/2 - Cov12 )
  组合 RB ≈ (1/2)ΣΣ RBij
  ```
- 等权、同波动、平均相关 ρ 的近似：
  ```
  RB ≈ (1/2)·σ^2·(1-ρ)·(1-1/N)      （N=10 时 1-1/N = 0.9）
  ```
  这是连续再平衡 / iid 近似；离散频率只捕获其中一部分。
- 直观：再平衡强制"**卖相对涨、买相对跌**"（Willenbrock 2011，§3 #2）；而 buy-and-hold 的增量收益来自"**赢家权重变大**"（同一篇）。两者来源不同、风险路径不同。

**量级直觉（只作先验）**：

| 个股年化 σ | ρ=0.5 | ρ=0.6 | ρ=0.7 |
|---|---|---|---|
| 22% | +1.09% | +0.87% | +0.65% |
| 25% | +1.41% | +1.13% | +0.84% |
| 28% | +1.76% | +1.41% | +1.06% |

→ 对 A 股 10 只高股息组合（σ≈22–25%、ρ≈0.5–0.7），**毛溢价先验约 +0.5%~+1.4%/年，中枢约 +1%/年**。这是"连续再平衡"的理论上限，实际按频率捕获、再扣成本/税后更低。

### 2.2 成立条件（缺一不可；第 3、4 条最容易被忽略）

1. **波动足够大**：σ² 项决定上限；低波动资产溢价近 0。
2. **不完全相关**：ρ<1；ρ→1 时 RB→0。同一行业/同一因子的股票（银行×银行）贡献很小。
3. **成分收益差不能太大 / 需要均值回复**：若组合里有长期赢家持续跑赢（趋势市、风格单边），buy-and-hold 的"赢家权重变大"会盖过再平衡。Bernstein 的 50/50 股债例子中，年再平衡 8.34% vs 算术加权 7.85%（+0.49%），但**不再平衡 9.17% 更高**——因为股票长期收益显著高于债券；"长期收益差 >5%/年时 hold 更优"（外部来源，§3 #1）。
4. **再平衡可低成本执行**：费用/税/冲击越小越好；频率越高成本越高。
5. **风险偏好**：再平衡的确定性收益是"保持风险恒定"（Willenbrock 2011）；收益层面的溢价是"可正可负"的附加项。

### 2.3 频率：理论不支持"月频一定最好"

- Bernstein 覆核 105 组资产对：月度再平衡最优 3 例、季度 4 例、年度 3 例——"**No one rebalancing period dominates**"（外部来源，§3 #1）。
- Arnott & Lovell 1968–91 的 50/50 股债：年 9.02%、季 9.12%、月 9.16%，扣成本后月频仍略优，但**量级仅 ~10–15bp**（外部来源，§3 #3）。
- 频率越高越能捕获"路径波动"，但交易成本大致随 √频率 增长（年换手 ∝1/√T，见 §4.2）；因此存在内部最优，而不是单调"越高越好"。
- 本研究先验：**月频 vs 季频的毛溢价差异预计 <0.3pp/年；加上噪声后，单篮排序不可信**。这正是 SPEC 要求 `RANDOM10×100` 的原因（`SPEC.md:96-98`）。

### 2.4 A 股高股息场景的特殊性

1. **行业集中与共同因子**：高股息池天然偏银行/煤炭/公用事业/交运/钢铁/地产链；即便 `L1≤1`、银行子类≤2（`01_PRD.md:153-154`；`config/strategy.yaml:21-24`），篮子仍与"红利风格"高度绑定 → **平均相关偏高，RB 偏小**。行业趋势（煤炭 2021–22 盈利顶、银行 2023–24 修复、电力 2021–24）会让"卖强买弱"变成逆向操作，**溢价可能转负**。
2. **动量/反转混合**：A 股既有中短期反转，也有中长期动量/风格趋势；高股息股 2024–2026 的慢牛会让"修剪赢家"降低收益（hold 的赢家权重变大占优，Willenbrock）；而 2015–2019 银行弱、2021–2024 红利强的 regime 切换又提供均值回复窗口。→ **溢价是 regime-dependent 的，历史上时有时无**。
3. **价值陷阱**："便宜可以继续更便宜"（`legacy/dev/01-data-layer.md:229`，按 §0 引用纪律）；再平衡加仓"跌出来的低配"可能是在加仓价值陷阱，这是负溢价的现实来源之一。
4. **股息率信号与修剪的重叠**：生产硬规则（股息率<1.5% / 满 5 年 / 浮盈>50% 清仓，`01_PRD.md:163-165`）本身就是极端修剪；常规 1/N 修剪与之部分重叠，**真实增量可能小于纯回测**。
5. **红利税批次**：见 §4.3；等权修剪多为"卖老批次"→多为 0%，但若卖出 <1 年批次，会把该批次分红从 0% 变 10%/20% 应税。
6. **A 股制度摩擦**：T+1、涨跌停不可买/卖、停牌（本 SPEC 用 ffill 价交易）、100 股整数手、卖出印花税 0.05%；300 万规模单笔 27–33 万，冲击小（`config/strategy.yaml:80` 注"真实滑点 1–3bp"），但极端月份（2015 股灾/停牌）可执行性会打折（`SPEC.md:147-153`）。
7. **现金与年度取现**：生产 10% 现金缓冲 + 年度取现 30%（`01_PRD.md:170-178`）未建模；`cash_only` 取现不卖股，但会减少可再投资现金，对 trim 的现金约束/换手有影响（`SPEC.md:151`）。
8. **分红再投口径**：后复权 = 分红按除权日价格再投原股票；生产按"当前市值权重"分摊（`SPEC.md:149`；`legacy/DESIGN.md:170`）→ 一阶近似，差异小但方向是"回测低估再投的分散化"。

**理论小结**：理论支持"小正值、区间宽、可负、regime 依赖"；不支持"月频显著优于其他频率"；A 股高股息的高相关 + 趋势会让毛溢价落在先验区间的**下沿**，甚至为负。

### 4.2 换手量级估算（解析近似；实际以 engine 的 `turnover_annual_two_way` / `cost_pct_annual` 为准）

假设：1/N 等权、个股年化波动 σ=22–25%、平均相关 ρ=0.5–0.7、自融资、无现金缓冲、全量重置。单期权重漂移：
```
δ_i ≈ (1/N)(r_i - r_p)
σ_δ = (1/N)·σ_m·sqrt( (1-ρ)(1-1/N) )
E|δ_i| ≈ 0.8·σ_δ
全组合两向成交额 ≈ Σ_i E|δ_i|
```
频率降低时单期漂移 ∝√T、年换手大致 ∝1/√T。

| 变体 | 两向年换手（估） | 年交易成本（17.3bp 口径） | `cost_mult=2` | 每次再平衡成本（bp/NAV） |
|---|---|---|---|---|
| `m_last`（月） | 32–47% | **2.8–4.1bp**（含 min 佣金约 4.6–5.9bp） | 约 6–8bp | 0.27–0.40 |
| `q`（季） | 22–32% | 1.9–2.8bp | 约 3.1–4.5bp | 0.48–0.70 |
| `s`（半年） | 13–19% | 1.1–1.7bp | 约 1.9–2.7bp | 0.68–0.95 |
| `a`（年） | 9–13% | 0.8–1.2bp | 约 1.4–2.0bp | 0.8–1.1 |
| `band5` / `band10` | ≤ 对应全量重置（取决于触发率） | 约 1–4bp | 约 2–7bp | — |

**分解（`m_last`，两向换手 40%）**：滑点约 2.0bp、印花税约 1.0bp、佣金/过户/经手/证管合计约 0.5bp → 合计约 3.5bp/年。→ **交易成本相对预期溢价（~100bp）是小扣减项，但它决定"费后符号"在毛溢价 <~10bp 时是否翻转。**

### 4.3 红利税：规则、机制与量级

**规则**（`01_PRD.md:203,209`；`legacy/rotation-engine.md:144-148`；`legacy/dev/03-backtest.md:60-70`）：

| 持股期限 | 股息红利个税实际税负 |
|---|---|
| ≤1 个月 | **20%** |
| 1 个月–1 年 | **10%** |
| >1 年 | **0%** |

FIFO 批次（`01_PRD.md:209`；`legacy/dev/03-backtest.md:60-70`）；v3.1 生产只补仓不卖股，正常路径不触发。

**机制（准确表述，避免"重置整个组合税率"的误读）**：分红到账时按档位处理/暂不扣缴；**卖出时按该批次的持股期限结算**。若某批次买入不足 1 年就被卖出，该批次持有期内收到的分红会从 0% 变为 10%/20% 应税——是**批次级、卖出触发**，不是对整个组合"重置"。

**量级估算**：

| 情形 | 假设 | 年化隐性税负 |
|---|---|---|
| 纯等权修剪（月度全量、FIFO 优先卖老批次、组合已运行 >1 年） | 卖出多为 >1 年批次 | **≈0bp** |
| 悲观（首批 <1 年被大量卖出） | 年卖出 25% NAV、平均持有 0.5 年、股息率 5% | 25%×5%×0.5×10% = **6.25bp**（一次性；摊到 5.5 年 ≈1bp/年） |
| 极端（卖出 <1 月批次） | 单次卖 5% NAV、持有 1 月、股息率 5% | 5%×5%×(1/12)×20% ≈ **0.42bp/次** |
| 对照：换股型高换手（legacy B7） | 换手 54%/年、中位持有 12 月、池均股息率≈6.58% | 0.54×6.58%×10% ≈ **35bp/年**（与 legacy 实测 0.35%/年吻合：`REPORT2.md:35-45`；`dev/03-backtest.md:69`） |

→ **等权修剪的红利税成本是"0–6bp/年"量级；换股轮动才是"~30bp/年"量级。** 本研究只做等权修剪，故税负扣减很小；但回测**未显式建模**（`SPEC.md:60` 明言分红已隐含在后复权价、不做二次现金流；`SPEC.md:147-153` 未建模批次税），方向是**净溢价被高估 0–5bp/年**（悲观假设下 ≤10bp）。

### 4.4 未建模项与"结论应打折的方向"汇总

| 未建模项 | 影响方向 | 量级估计 |
|---|---|---|
| 红利税批次重置（等权修剪） | 高估净溢价 | 0–5bp/年（≤10bp 悲观） |
| 滑点 5bp 是简化（真实冲击/停牌/涨跌停） | 高估净溢价 | `cost_mult` 已覆盖到 ~2×；极端月份更大 |
| 涨跌停不可成交 / 停牌 ffill 交易 / T+1 / 100 股整数手 | 高估可执行性 | 少数月份，难以量化 |
| 10% 现金缓冲 + 年度取现 30%（cash_only 不卖股） | 可能低估/改变再平衡约束 | 一阶近似（`SPEC.md:151`） |
| 后复权 vs 市值权重再投的分红口径 | 轻微高估/低估 | 小（`SPEC.md:149`） |
| 幸存者偏差（61 只均为 2026 仍在册） | 对溢价差影响小（A/B 同篮子）；对绝对收益高估 | `SPEC.md:147`；`REPORT.md:130-136` |
| 单篮样本噪声 | 最大的方向性风险 | 见 §5.4 |

**打折结论**：温和情形下调 **5–15bp/年**；若把滑点/冲击按 legacy 10bp 双边口径，再下调 ~5bp/年。**不足以扭转 >0.5%/yr 的毛溢价，但足以让 <0.2%/yr 的毛溢价变成"费后≈0/负"。**

### 4.5 一句话

**成本/税在本研究里是"小量、方向确定"的扣减项（`m_last` 约 5–7bp/年量级，`cost×2` 约 8–10bp/年量级）；真正的结论风险在毛溢价本身与样本噪声，不在费用。**（legacy 也得出"成本不是主要矛盾"：`dev/03-backtest.md:88`；`rotation-engine.md:335`。）

## 5. 结论草案（先验预期，供 Lead 与 engine 结果合并）

> 本节是**先验**，不是最终结论。最终以 `results/RESULTS_DRAFT.md` + 独立复核为准；若冲突，以 engine/verifier 数字优先，本文件只负责解释。

### 5.1 毛溢价先验

- 公式先验：**+0.5%~+1.4%/年，中枢 +1%/年**（σ 22–25%、ρ 0.5–0.7、N=10；§2.1）。
- 下修因素：ρ 若 >0.7、篮子内行业趋势强、2015–2026 收益分化大 → 可能落到 0–0.5%，甚至为负；上修因素：若组合内个股强弱交替明显（均值回复强），可到 +1.5% 以上。
- 频率差异先验：`m_last` ≈ `q` > `s` ≈ `a` 的差异预计 <0.3pp/年；`band5/band10` 与 `m_last` 接近但换手更低。

### 5.2 费后先验

- 交易成本：`m_last` 约 3–6bp/年（含 min 佣金），`q` 约 2–3bp，`a` 约 1bp；`cost×2` 约 6–8bp/年。
- 红利税：等权修剪 0–5bp/年。
- 合计扣减：**约 5–12bp/年** → 费后中枢 **+0.8~+1.3%/年**（`m_last`/`q`），但**大概率统计上不显著、与 0 不可区分**；若毛溢价 <20bp/年，费后可能≈0 或负。

### 5.3 频率先验

- 理论（外部证据）**不支持月频显著最优**；A 股高相关/趋势更支持"低频或 band 触发"。预计 `m_last`、`q`、`band5` 的费后 CAGR 差异在 ±0.3pp/年内，多数落在噪声里。
- 因此：**不要用单篮频率排序写成结论**；以 `RANDOM10×100` 的溢价均值/中位数/正比例/跨篮子 t 检验为主（`SPEC.md:96-98`）。

### 5.4 统计功效警告（必须写进最终报告）

若月度收益差的标准差 σ_diff≈2%，要检出 +1%/年（月均≈0.083%）：
- 5.5 年（n≈66）：SE≈0.246% → **t≈0.34**；
- 11.8 年（n≈142）：SE≈0.168% → **t≈0.49**。

→ **单篮 `monthly_diff_p<0.05` 几乎不可能**；不要把"不显著"误读为"溢价不存在"，也不要把"单篮正溢价"当成 alpha。应看：
1. `RANDOM10` 的**正比例**（如 60/100 为正，符号检验 p≈0.02）与跨篮子均值 t；
2. 溢价与理论量级（§2.1）是否一致；
3. `m_last_nocost − m_last ≈ cost_pct_annual` 的单调性（`SPEC.md:116`）；
4. `cost_pct_annual` 是否与 `turnover×8.64bp` 同量级（若 >15bp，先查双边/换手口径）。

### 5.5 与生产结合（供 Lead 判断，不越权定策）

- 生产 v3.1 = "月频仅补仓到 N，不主动换股"（`01_PRD.md:156`；`config/strategy.yaml:28`；`IMPLEMENTATION.md:66`）→ 只有**单边补仓**，没有修剪；本研究若显示 `m_last` 正溢价，含义是"补上修剪"可能有小增量，但**增量小且必须前瞻验证**。
- 生产已有"浮盈>50% 一次性清仓 / 满 5 年 / 股息率<1.5%"（`01_PRD.md:163-165`；`config/strategy.yaml:30-35`）——极端修剪已被规则覆盖，常规 1/N 修剪的真实增量会比回测更小。
- 纪律：样本 <3 年不得展示年化超额（`01_PRD.md:114`；`00_INDEX.md:60`）；本研究结果不得写成"已验证收益"；**禁止开启 rotation**（`config/strategy.yaml:37`；`05_DEVELOPMENT.md:582,594`）。
